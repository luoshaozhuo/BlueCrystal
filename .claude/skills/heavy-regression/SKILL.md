# heavy-regression

## 功能

用户明确要求时运行重回归、长测或发布前验证。

## 通用要求

1. 使用中文输出。
2. 不默认读取所有文档。
3. 只读取完成本技能所需的文件。
4. 当前仓库文件是事实来源。
5. 反馈必须简洁。

## 步骤

1. 读取 `ai_shared/rules/validation-routing.md`。
2. 根据用户指定范围运行重回归或长测。
3. 汇总通过项、失败项、耗时、失败摘要。
4. 不擅自扩大范围。
