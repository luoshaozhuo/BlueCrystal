# 4+1 视图关注点与常用 UML 图形

## 1. 逻辑视图（Logical View）

| 关注点 | 说明 | 常用 UML 图 |
|--------|------|--------------|
| 功能分解 | 系统提供哪些功能模块 | 包图、用例图 |
| 关键抽象 | 核心类 / 对象 / 接口 | 类图 |
| 静态关系 | 继承、关联、依赖、组合 | 类图 |
| 模块 / 分层 | 分层结构（如 UI-业务-数据） | 包图、组件图 |
| 对象状态 | 关键对象的状态变化 | 状态图 |
| 内部流程 | 单个类或方法的逻辑 | 活动图 |

---

## 2. 过程视图（Process View）

| 关注点 | 说明 | 常用 UML 图 |
|--------|------|--------------|
| 进程 / 线程 | 运行时进程与线程划分 | 进程图（非标准 UML，可用组件图代替） |
| 交互时序 | 进程 / 线程间的交互顺序 | **时序图（最常用）** |
| 并发控制 | 锁、同步、竞态条件 | 活动图（带并发区域） |
| 通信机制 | IPC、RPC、消息队列、协议 | 时序图、通信图 |
| 状态迁移 | 进程或服务的运行状态 | 状态图 |
| 启动 / 关闭 | 初始化顺序、优雅关闭 | 活动图、时序图 |

---

## 3. 开发视图（Development View）

| 关注点 | 说明 | 常用 UML 图 |
|--------|------|--------------|
| 模块组织 | 代码模块 / 包 / 命名空间划分 | 包图 |
| 编译依赖 | 模块间的编译 / 构建依赖 | 包图（带依赖箭头） |
| 目录结构 | 源代码目录树 | **非 UML，常用目录树文本** |
| 版本控制 | 分支策略、模块归属 | 非 UML |
| 构建 / 部署制品 | JAR、DLL、Docker 镜像等 | 组件图、制品图 |

> 说明：开发视图常混用 UML 与非 UML 表示，包图为核心 U ML 工具。

---

## 4. 物理视图（Physical View）

| 关注点 | 说明 | 常用 UML 图 |
|--------|------|--------------|
| 硬件节点 | 物理机 / 虚拟机 / 容器 | **部署图** |
| 软件到硬件映射 | 每个软件部署在哪个节点 | 部署图 |
| 网络拓扑 | 节点间网络连接、协议 | 部署图（带连接线） |
| 冗余 / 高可用 | 主备、集群、负载均衡 | 部署图 |
| 资源约束 | CPU / 内存 / 存储规格 | 部署图（节点标注） |

---

## 5. 场景视图（Scenarios / Use Cases）

| 关注点 | 说明 | 常用 UML 图 |
|--------|------|--------------|
| 关键用例 | 最具代表性的业务场景 | **用例图** |
| 用例流程 | 正常 / 异常路径 | 活动图、时序图 |
| 视图一致性验证 | 上述四个视图是否支持该用例 | 文本描述 + 交叉引用 |

---

## 快速记忆表（一句话 + 一图）

| 视图 | 一句话 | 核心图 |
|------|--------|--------|
| 逻辑 | 系统由哪些静态元素组成 | 类图 |
| 过程 | 运行时谁跟谁在什么时候通信 | 时序图 |
| 开发 | 代码和模块如何组织 | 包图 |
| 物理 | 软件安装在哪些机器上 | 部署图 |
| 场景 | 用实例串联和验证以上视图 | 用例图 |
