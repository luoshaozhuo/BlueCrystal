### 1. 标准概述

IEC 61850 是国际电工委员会（IEC）发布的**变电站自动化**通信标准。其核心设计哲学是 **"数据模型与通信协议解耦"**（ACSI / SCSM 分离），支持未来新协议的平滑接入。

核心目标：

- 设备互操作性（不同厂商设备可互联）
- 面向对象的数据建模
- 高速实时通信（GOOSE/SV）
- 统一的工程配置（SCD）

### 2. 核心概念体系

#### 2.1 关键术语

| 术语 | 含义 | 类比 |
|------|------|------|
| **SCD** | 变电站配置描述文件，XML 格式，包含全站所有 IED 的模型、通信参数、订阅关系 | 图书馆的藏馆地图 |
| **IED** | 智能电子设备，如保护装置、测控单元、合并单元 | 一个书架 |
| **LDevice** | 逻辑设备，IED 内部的功能分组 | 书架的一层 |
| **LN（逻辑节点）** | 功能的最小单元，如 `PTRC`（保护跳闸）、`XCBR`（断路器）、`MMXU`（测量） | 分类标签 |
| **DO（数据对象）** | 逻辑节点下的数据集合，如 `Op`（操作） | 一本书 |
| **DA（数据属性）** | 数据对象的具体属性，如 `general`（总信号）、`phsA`（A相） | 书的章节 |
| **LLN0** | 每个 LDevice 下的**管理逻辑节点**，所有 DataSet 和通信控制块均挂载于此 | 管理员 |
| **DataSet（数据集）** | DO/DA 的引用列表，定义"要发哪些数据"，本身不存储数据 | 快捷方式列表 |
| **FCDA** | 数据集中的条目，精确定位到 `LD/LN.DO.DA` | 快捷方式 |
| **FC（功能约束）** | 标识数据的用途：`ST`（状态）、`MX`（测量）、`CF`（配置）、`CO`（控制）等 | - |
| **控制块** | `GSEControl`（GOOSE）、`SampledValueControl`（SV），通过 `datSet` 关联 DataSet，定义"怎么发" | 快递单 |
| **数据类型模板** | 在 `DataTypeTemplates` 中定义 LN/DO/DA 的"类"，供 IED 实例引用 | 模具/零件库 |

#### 2.2 数据引用路径（Object Reference）

格式：`<LDName>/<LNName>.<DOName>.<DAName>`

示例：`PROT/PTRC1.Op.general` 表示：

- 逻辑设备 `PROT`
- 逻辑节点 `PTRC1`（保护跳闸实例 1）
- 数据对象 `Op`（操作）
- 数据属性 `general`（总跳闸信号）

#### 2.3 LN0 的特殊角色

`LLN0` 是**每个 LDevice 下的管理逻辑节点**，它承担：

- **管理功能**：挂载 `NamPlt`（铭牌）、`Beh`（行为）等管理数据
- **通信功能**：所有 `DataSet`、`GSEControl`、`SampledValueControl` 均定义在 `LN0` 下

**普通 LN**（如 `PTRC1`、`XCBR1`）负责具体的业务功能，而 **`LN0` 负责"怎么把数据发出去"**。

#### 2.4 数据集与 LN 的关系

数据集**挂载在 `LN0` 下**，但**可以引用任何 LN 的数据**。判断数据集包含什么内容，必须查看其内部的 `<FCDA>` 成员列表，而非看它挂在哪里。

数据集可以跨 LN 引用：

```xml
<DataSet name="dsGOOSE">
    <FCDA ldInst="LD0" lnClass="PTRC" lnInst="1" doName="Op" daName="general" fc="ST"/>
    <FCDA ldInst="LD0" lnClass="XCBR" lnInst="1" doName="Pos" daName="stVal" fc="ST"/>
</DataSet>
```

### 3. SCD 文件结构详解

#### 3.1 总体结构

SCD 文件是 XML 格式，遵循 **"先定义模板，再实例化设备，最后配置通信"** 的逻辑顺序：

```text
SCL (根节点)
├── Header (文件元数据)
├── Communication (通信参数)
│   └── SubNetwork
│       └── ConnectedAP (关联到具体 IED)
│           ├── GSE (GOOSE 地址 + 心跳参数)
│           └── SMV (SV 地址)
├── IED (设备实例，可以有多个)
│   ├── AccessPoint
│   │   └── Server
│   │       └── LDevice
│   │           ├── LN0 (管理节点)
│   │           │   ├── DataSet (通过 FCDA 引用数据)
│   │           │   ├── GSEControl (关联 DataSet，定义 GOOSE 参数)
│   │           │   └── SampledValueControl (关联 DataSet，定义 SV 参数)
│   │           ├── LN (普通逻辑节点，通过 lnType 引用模板)
│   │           └── DOI (实例化数据对象的值)
│   └── (AccessPoint 可配置 GOOSE/SV 订阅的 Inputs)
├── Substation (一次设备拓扑，可选)
└── DataTypeTemplates (数据类型模板库)
    ├── LNodeType (定义 LN 包含哪些 DO)
    ├── DOType (定义 DO 包含哪些 DA)
    └── DAType (定义复杂数据类型的嵌套结构)
```

#### 3.2 完整 SCD 示例（含 GOOSE + SV + 心跳配置）

```xml
<?xml version="1.0" encoding="UTF-8"?>
<SCL xmlns="http://www.iec.ch/61850/2003/SCL">
    <Header id="SampleSubstation" toolID="ConfigTool" version="1.0" revision="1.0"/>

    <!-- ========================================= -->
    <!-- 1. Communication：通信参数配置           -->
    <!-- ========================================= -->
    <Communication>
        <SubNetwork name="ProcessBus" type="8-MMS">
            <!-- IED1 的 GOOSE 发布配置 -->
            <ConnectedAP iedName="IED1" apName="G1">
                <!-- GOOSE 控制块地址 + 心跳参数 -->
                <GSE cbName="GOcb1" ldInst="LD0">
                    <Address>
                        <P type="MAC-Address">01-0C-CD-01-00-01</P>
                        <P type="APPID">1001</P>
                        <P type="VLAN-ID">001</P>
                        <P type="VLAN-PRIORITY">4</P>
                    </Address>
                    <!-- 心跳/重传参数：IEC 61850 标准定义 -->
                    <MinTime unit="s">0.02</MinTime>   <!-- 事件触发后快速重传间隔：20ms -->
                    <MaxTime unit="s">5.0</MaxTime>    <!-- 数据稳定后心跳间隔：5秒 -->
                </GSE>
                <!-- SV 控制块地址配置 -->
                <SMV cbName="SVcb1" ldInst="LD0">
                    <Address>
                        <P type="MAC-Address">01-0C-CD-04-00-01</P>
                        <P type="APPID">4001</P>
                        <P type="VLAN-ID">001</P>
                        <P type="VLAN-PRIORITY">4</P>
                    </Address>
                </SMV>
            </ConnectedAP>
        </SubNetwork>
    </Communication>

    <!-- ========================================= -->
    <!-- 2. IED1：发布方设备（保护装置）           -->
    <!-- ========================================= -->
    <IED name="IED1" manufacturer="DemoManuf" type="Protection">
        <AccessPoint name="G1">
            <Server>
                <LDevice inst="LD0">
                    <!-- LN0：管理节点 -->
                    <LN0 lnClass="LLN0" inst="" lnType="Demo_LLN0">
                        <!-- 铭牌实例化 -->
                        <DOI name="NamPlt">
                            <DAI name="vendor">
                                <Val>Demo Manufacturer</Val>
                            </DAI>
                        </DOI>

                        <!-- ====== 数据集定义 ====== -->
                        <!-- SV 数据集：包含测量值 -->
                        <DataSet name="dsSV">
                            <FCDA ldInst="LD0" lnClass="MMXU" lnInst="1" 
                                  doName="PhV" daName="cVal.mag.f" fc="MX"/>
                            <FCDA ldInst="LD0" lnClass="MMXU" lnInst="1" 
                                  doName="A" daName="cVal.mag.f" fc="MX"/>
                        </DataSet>

                        <!-- GOOSE 数据集：包含状态量 -->
                        <DataSet name="dsGOOSE">
                            <FCDA ldInst="LD0" lnClass="PTRC" lnInst="1" 
                                  doName="Op" daName="general" fc="ST"/>
                            <FCDA ldInst="LD0" lnClass="PTRC" lnInst="1" 
                                  doName="Op" daName="phsA" fc="ST"/>
                            <FCDA ldInst="LD0" lnClass="PTRC" lnInst="1" 
                                  doName="Op" daName="phsB" fc="ST"/>
                            <FCDA ldInst="LD0" lnClass="PTRC" lnInst="1" 
                                  doName="Op" daName="phsC" fc="ST"/>
                            <FCDA ldInst="LD0" lnClass="XCBR" lnInst="1" 
                                  doName="Pos" daName="stVal" fc="ST"/>
                        </DataSet>

                        <!-- ====== SV 控制块 ====== -->
                        <!-- 通过 datSet 关联 dsSV，smvID 全站唯一 -->
                        <SampledValueControl name="SVcb1" 
                                             datSet="dsSV" 
                                             smvID="IED1/LD0/SVcb1" 
                                             confRev="1"/>

                        <!-- ====== GOOSE 控制块 ====== -->
                        <!-- 通过 datSet 关联 dsGOOSE，appID 全站唯一 -->
                        <GSEControl name="GOcb1" 
                                    datSet="dsGOOSE" 
                                    appID="1001" 
                                    confRev="1"/>
                    </LN0>

                    <!-- ====== 普通逻辑节点实例 ====== -->
                    <!-- 测量逻辑节点 -->
                    <LN lnClass="MMXU" inst="1" lnType="Demo_MMXU">
                        <DOI name="PhV">
                            <DAI name="cVal.mag.f">
                                <Val>0.0</Val>  <!-- 运行时由PLC填充 -->
                            </DAI>
                        </DOI>
                    </LN>

                    <!-- 保护跳闸逻辑节点 -->
                    <LN lnClass="PTRC" inst="1" lnType="Demo_PTRC">
                        <DOI name="Op">
                            <DAI name="general">
                                <Val>false</Val>
                            </DAI>
                        </DOI>
                    </LN>

                    <!-- 断路器逻辑节点 -->
                    <LN lnClass="XCBR" inst="1" lnType="Demo_XCBR">
                        <DOI name="Pos">
                            <DAI name="stVal">
                                <Val>false</Val>
                            </DAI>
                        </DOI>
                    </LN>
                </LDevice>
            </Server>
        </AccessPoint>
    </IED>

    <!-- ========================================= -->
    <!-- 3. IED2：订阅方设备（测控装置）           -->
    <!-- ========================================= -->
    <IED name="IED2" manufacturer="DemoManuf" type="Control">
        <AccessPoint name="G1">
            <Server>
                <LDevice inst="CTRL">
                    <LN0 lnClass="LLN0" inst="">
                        <!-- Inputs：声明要订阅的外部数据 -->
                        <Inputs>
                            <!-- 订阅 IED1 的 GOOSE 数据集中的跳闸信号 -->
                            <ExtRef iedName="IED1" 
                                    ldInst="LD0" 
                                    lnClass="PTRC" lnInst="1"
                                    doName="Op" daName="general"
                                    intAddr="GOOSEIN.1"/>
                            <!-- 订阅 IED1 的 GOOSE 数据集中的断路器位置 -->
                            <ExtRef iedName="IED1" 
                                    ldInst="LD0" 
                                    lnClass="XCBR" lnInst="1"
                                    doName="Pos" daName="stVal"
                                    intAddr="GOOSEIN.2"/>
                        </Inputs>
                    </LN0>
                    <!-- 本IED的断路器逻辑节点 -->
                    <LN lnClass="XCBR" inst="1" lnType="Demo_XCBR"/>
                </LDevice>
            </Server>
        </AccessPoint>
    </IED>

    <!-- ========================================= -->
    <!-- 4. DataTypeTemplates：数据类型模板库      -->
    <!-- ========================================= -->
    <DataTypeTemplates>
        <!-- 定义 LLN0 模板 -->
        <LNodeType lnClass="LLN0" id="Demo_LLN0">
            <DO name="Mod" type="Demo_Mod"/>
            <DO name="NamPlt" type="Demo_LPL"/>
        </LNodeType>

        <!-- 定义 MMXU 模板 -->
        <LNodeType lnClass="MMXU" id="Demo_MMXU">
            <DO name="PhV" type="Demo_WYE"/>   <!-- 三相电压 -->
            <DO name="A" type="Demo_WYE"/>     <!-- 三相电流 -->
        </LNodeType>

        <!-- 定义 PTRC 模板 -->
        <LNodeType lnClass="PTRC" id="Demo_PTRC">
            <DO name="Op" type="Demo_ACT_3Phase"/>
        </LNodeType>

        <!-- 定义 XCBR 模板 -->
        <LNodeType lnClass="XCBR" id="Demo_XCBR">
            <DO name="Pos" type="Demo_SPS"/>
        </LNodeType>

        <!-- 定义 SPS (单点状态) 数据对象 -->
        <DOType id="Demo_SPS" cdc="SPS">
            <DA bType="BOOLEAN" name="stVal" fc="ST" dchg="true"/>
            <DA bType="Quality" name="q" fc="ST"/>
            <DA bType="Timestamp" name="t" fc="ST"/>
        </DOType>

        <!-- 定义 ACT_3Phase (三相动作) 数据对象 -->
        <DOType id="Demo_ACT_3Phase" cdc="ACT">
            <DA bType="BOOLEAN" name="general" fc="ST" dchg="true"/>
            <DA bType="BOOLEAN" name="phsA" fc="ST" dchg="true"/>
            <DA bType="BOOLEAN" name="phsB" fc="ST" dchg="true"/>
            <DA bType="BOOLEAN" name="phsC" fc="ST" dchg="true"/>
        </DOType>

        <!-- 定义 WYE (三相测量值) 数据对象 -->
        <DOType id="Demo_WYE" cdc="WYE">
            <DO name="phsA" type="Demo_CMV"/>
            <DO name="phsB" type="Demo_CMV"/>
            <DO name="phsC" type="Demo_CMV"/>
        </DOType>

        <!-- 定义 CMV (复数测量值) 数据对象 -->
        <DOType id="Demo_CMV" cdc="CMV">
            <DO name="cVal" type="Demo_Vector"/>
            <DA bType="Quality" name="q" fc="MX"/>
        </DOType>

        <!-- 定义 Vector (矢量) 数据类型 -->
        <DAType id="Demo_Vector">
            <BDA bType="FLOAT32" name="mag"/>
            <BDA bType="FLOAT32" name="ang"/>
        </DAType>

        <!-- 定义 LPL (铭牌) 数据对象 -->
        <DOType id="Demo_LPL" cdc="LPL">
            <DA bType="VisibleString255" name="vendor" fc="DC"/>
            <DA bType="VisibleString255" name="model" fc="DC"/>
            <DA bType="VisibleString255" name="swRev" fc="DC"/>
        </DOType>

        <!-- 定义 Mod (模式) 数据对象 -->
        <DOType id="Demo_Mod" cdc="INC">
            <DA bType="Enum" name="stVal" fc="ST"/>
        </DOType>
    </DataTypeTemplates>
</SCL>
```

#### 3.3 SCD 中 GOOSE 心跳配置说明

| 参数 | 位置 | 含义 |
|------|------|------|
| `MinTime` | `<GSE>` 下 | 事件触发后的快速重传间隔（如 20ms） |
| `MaxTime` | `<GSE>` 下 | 数据稳定后的心跳发送间隔（如 5s） |

如果 SCD 中未配置 `MinTime` / `MaxTime`：

- 设备不会按标准的心跳机制发送报文
- 可能导致订阅方无法准确判断通信链路状态
- 部分设备可能按内部默认值发送，但无统一标准

#### 3.4 SCD 配置的订阅方参数提取

订阅方代码需要从 SCD 中提取以下关键参数：

| 协议 | 必须参数 | SCD 中位置 |
|------|----------|------------|
| GOOSE | `MAC-Address` | `Communication/ConnectedAP/GSE/Address/P[type="MAC-Address"]` |
| GOOSE | `APPID` | `Communication/ConnectedAP/GSE/Address/P[type="APPID"]` |
| GOOSE | `GoCBRef` | `IED/AccessPoint/Server/LDevice/LN0/GSEControl/name`（结合 IED 名称和 LD 实例） |
| SV | `MAC-Address` | `Communication/ConnectedAP/SMV/Address/P[type="MAC-Address"]` |
| SV | `APPID` | `Communication/ConnectedAP/SMV/Address/P[type="APPID"]` |
| SV | `svID` / `smvID` | `IED/AccessPoint/Server/LDevice/LN0/SampledValueControl/smvID` |

### 4. 三大协议详解

#### 4.1 MMS（制造报文规范）

| 属性 | 说明 |
|------|------|
| 用途 | 读写数据、修改定值、获取报告、文件传输 |
| 通信方式 | TCP/IP，客户端/服务器模式 |
| 端口 | `102` |
| 典型延迟 | 数百毫秒 |
| 典型应用 | 监控后台与 IED 之间的数据交互 |

主要操作：

- `Read`：读取单个或多个数据属性
- `Write`：写入单个或多个数据属性
- `GetNameList`：获取对象名称列表
- `Report`：报告（由报告控制块触发）
- `Select` / `Operate`：SBO 控制模型

#### 4.2 GOOSE（面向通用对象的变电站事件）

| 属性 | 说明 |
|------|------|
| 用途 | 快速传输状态变化（跳闸、断路器位置、联锁信号） |
| 通信方式 | 多播/广播，直接映射到数据链路层 |
| 典型延迟 | &lt; 4 ms |
| 可靠机制 | 事件触发 + 快速重传 + 心跳 |
| 典型应用 | 保护跳闸、断路器位置、互锁逻辑 |

发送机制：

- **事件触发**：`DataSet` 中任一数据值变化时，立即发送报文。
- **快速重传**：以 `MinTime` 间隔（如 2 ms、4 ms、20 ms）连续重发数次。
- **心跳**：数据稳定后，以 `MaxTime` 间隔（如 5 s）持续发送心跳报文。

报文头部关键字段：

| 字段 | 含义 |
|------|------|
| `stNum`（状态号） | 数据集变化计数器，每次变化 `+1` |
| `sqNum`（顺序号） | 当前 `stNum` 下的报文序号，逐帧递增 |
| `timeAllowedToLive` | 允许生存时间，接收方据此判断通信是否中断 |

GOOSE 订阅方逻辑：

1. 接收报文。
2. 检查 `stNum`：若变化，则处理新数据（事件）；若不变，则视为心跳，数据无变化。
3. 检测心跳超时：若超过 2 倍 `MaxTime` 未收到报文，则告警；超过 4 倍，则判定通信中断。

#### 4.3 SV（采样值 Sampled Values）

| 属性 | 说明 |
|------|------|
| 用途 | 传输原始采样值（电流、电压波形） |
| 通信方式 | 多播，直接映射到数据链路层 |
| 发送机制 | 固定采样率，连续不间断发送 |
| 典型采样率 | 4000 帧/秒（80 点/周波，50 Hz），4800 帧/秒（96 点/周波，60 Hz） |
| 可靠机制 | 无重传，通过 `smpCnt` 检查连续性 |
| 典型应用 | 合并单元向保护/测控/录波装置发送采样数据 |

与 GOOSE 的核心区别：

| 对比维度 | GOOSE | SV |
|----------|-------|----|
| 数据类型 | 状态量（Boolean） | 模拟量（Float） |
| 发送频率 | 事件触发 + 心跳 | 固定采样率，连续流 |
| 是否重传 | 是（快速重传） | 否 |
| 数据量 | 小（几个布尔值） | 大（多通道波形） |
| 典型延迟要求 | &lt; 4 ms | &lt; 1 ms |

### 5. 控制模型

#### 5.1 Write（写入）

直接修改数据属性值，用于修改参数或设置值。

```python
client.write("LD/GGIO1.AnIn1.mag.f", 42.5)
```

#### 5.2 Operate（操作）

用于执行控制命令（如合闸、分闸），需遵循 SBO（先选择后操作）安全流程：

1. **Select**：客户端发送选择命令，锁定控制对象。
2. **Check**：设备校验权限和状态。
3. **Operate**：客户端发送执行命令。
4. **Execute**：设备执行操作，返回结果。

SBO 的作用：防止多个客户端同时控制同一对象，超时自动释放锁。

### 6. Python 开发（pyiec61850-ng 库）

#### 6.1 库的性质

`pyiec61850-ng` 是基于开源 C 库 `libiec61850` 的 Python 绑定，非 IEC 或设备厂商官方发布，但社区活跃。支持 MMS、GOOSE、SV 三大协议。

#### 6.2 安装

```bash
pip install pyiec61850-ng
```

性能注意：GOOSE 和 SV 功能在 Linux 下表现更好，且通常需要 root 权限创建原始套接字（raw socket）。

#### 6.3 MMS 客户端操作

```python
from pyiec61850.mms import MMSClient

# 连接
with MMSClient("192.168.1.100") as client:
    # 获取服务器信息
    identity = client.get_server_identity()
    print(f"厂商: {identity.vendor}")

    # 浏览数据模型
    for device in client.get_logical_devices():
        for node in client.get_logical_nodes(device):
            for obj in client.get_data_objects(device, node):
                print(f"DO: {device}/{node}.{obj}")

    # 读取单个值
    value = client.read_value("LD/MMXU1.TotW.mag.f")

    # 批量读取数据集
    values = client.read_dataset("LD/LLN0.dsAnalog")

    # 写入
    client.write("LD/GGIO1.AnIn1.mag.f", 42.5)

    # SBO 控制
    client.select("LD/XCBR1.Pos")
    client.operate("LD/XCBR1.Pos", True)
```

#### 6.4 GOOSE 订阅

```python
from pyiec61850.goose import GooseSubscriber

# 参数从 SCD 中提取
sub = GooseSubscriber(
    mac_address="01:0C:CD:01:00:01",
    app_id=0x1001,
    vlan_priority=4,
    vlan_id=0,
)

sub.subscribe()
try:
    pdu = sub.receive(timeout=5000)
    if pdu:
        print(f"stNum: {pdu.stNum}, sqNum: {pdu.sqNum}")
        # 检查 stNum 变化判断是否为事件
        for data in pdu.data:
            print(f"数据: {data}")
finally:
    sub.unsubscribe()
```

#### 6.5 SV 订阅

```python
from pyiec61850.sv import SVSubscriber

# 参数从 SCD 中提取
sub = SVSubscriber(
    sv_id="IED1/LD0/SVcb1",           # 来自 smvID
    mac_address="01:0C:CD:04:00:01",
    app_id=0x4001,
    vlan_priority=4,
    vlan_id=0,
)

sub.subscribe()
try:
    pdu = sub.receive(timeout=5000)
    if pdu:
        print(f"smpCnt: {pdu.smpCnt}")  # 检查连续性判断是否丢帧
        for channel in pdu.data:
            print(f"通道值: {channel.mag.f}")
finally:
    sub.unsubscribe()
```
