# 外部 AI 生成 Coding Agent 执行 Prompt 模板

本模板用于 ChatGPT / Gemini / DeepSeek 网页端，目的是生成可直接交给 Claude Code / Codex 的上下文无关执行 prompt。

## 1. 任务总目标

说明本任务最终要达成什么业务或工程目标。

## 2. 当前进展 / 已有事实

说明当前已经完成什么、已有文件、反馈、错误、上一轮结论是什么。

要求：

- 不依赖历史会话。
- 必要背景必须写清楚。
- 不确定的信息明确标注为“不确定”。

## 3. 禁止项 / 边界

说明本轮不能做什么。

示例：

- 不修改数据库 schema。
- 不恢复废弃文件。
- 不引入新依赖。
- 不做大范围重构。
- 不改变既有 CLI 参数。
- 不降低测试断言。
- 不跳过必要验证。

## 4. 本轮工作内容与步骤

说明本轮具体要做什么，建议按步骤列出。

## 5. 验证方法

说明本轮至少需要如何验证。

示例：

- 根据公共规则选择最小验证。
- 涉及 Python 时运行相关 ruff/mypy/pytest。
- 涉及 C/native 时运行 build 或 native protocol tests。
- 涉及 schema/config 时运行 schema/config/repository tests。
- 不运行重回归，除非明确要求。

## 6. 额外反馈要求

填写本轮特别需要关注的反馈项。

示例：

- 是否影响 schema。
- 是否影响 CLI。
- 是否影响性能指标。
- 是否建议 ADR。
- 是否建议后续长测。
