# Coding Task Prompt 模板生成说明

本文件用于生成由 Claude Code / OpenAI Codex 当前主会话直接执行的 prompt。不复制 `CLAUDE.md` 和 `ai_shared/rules/` 正文，只写当前任务的目标、范围和阶段参数。

## 1. 阶段模型

```text
普通会话请求 -> 当前主会话执行编码阶段
/test              -> 当前主会话执行测试阶段
/validate          -> 当前主会话执行验证阶段
/test-all          -> 当前主会话执行全量测试阶段
```

四个阶段完全独立，不得自动串联。所有阶段及规则、需求、报告或 project_tree 任务都由当前主会话直接执行，不启动、委派或切换到独立 agent。

## 2. 编码阶段任务

```text
- stage: coding
- task:
  - {IMPLEMENT_TASK}
- allowed paths:
  - {ALLOWED_PATH}
- forbidden paths:
  - {FORBIDDEN_PATH}
- required files:
  - ai_shared/rules/routing.md
  - ai_shared/rules/coding.md
  - ai_shared/rules/python-docstring-cn.md
  - {REQUIRED_FILE}
- changed files:
  - 使用 changed-files-gate 保护用户已有变更
- checks:
  - 不执行测试、验证、syntax、lint、type-check 或质量门禁
- output:
  - 只说明修改文件、行为变化和必要实现风险
  - 不输出检查状态，不例行提示检查命令
```

## 3. `/test` 任务

```text
- validation_stage: test
- task:
  - 测试 staged 变更直接修改的代码
- allowed paths:
  - tests/
  - 任务相关 fixture/mock/fake/stub
- forbidden:
  - 原则上不修改生产代码
  - 不扩大到引用方、跨模块或全仓范围
- scope:
  - git diff --cached 是唯一范围起点
  - git diff 仅用于识别 MIXED_INDEX_FILE
  - unstaged 和 untracked 内容不纳入范围起点
- skills:
  - changed-files-gate
  - code-quality-gate
- output:
  - 按 reporting.md 的 /test 反馈
```

## 4. `/validate` 任务

```text
- validation_stage: validate
- read_only: true
- task:
  - 从 staged 变更扩大到真实引用方、依赖方和装配路径进行验证
- forbidden:
  - 不得修改源码、测试或文档
  - 不自动扩大为全仓测试
- skills:
  - changed-files-gate
  - code-quality-gate
- output:
  - 按 reporting.md 的 /validate 反馈
```

## 5. `/test-all` 任务

```text
- validation_stage: test-all
- read_only: true
- include_heavy: {TRUE_OR_FALSE}
- task:
  - 对当前整个工作区执行全仓常规工具链和全部常规自动化测试
- forbidden:
  - 不得修改源码、测试或文档
  - include_heavy=false 时不得执行性能、长稳、真实外部依赖或完整部署演练
- skills:
  - changed-files-gate
  - code-quality-gate
  - heavy-regression if include_heavy=true
- output:
  - 按 reporting.md 的 /test-all 反馈
```

## 6. 公共边界

1. `project-tree-update`、`project-tree-reset`、`heavy-regression`、`commit-message` 和 Git/GitHub 写操作只在用户明确要求时执行。
2. project_tree 只用于导航，不替代真实源码、测试、配置和 schema。
3. 任何阶段都不得自动触发下一阶段。
4. 任何阶段都不得启动、委派或切换到独立 agent。
