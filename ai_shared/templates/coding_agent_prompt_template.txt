# Coding Agent Prompt 模板生成说明

本文件给网页版 LLM 使用，用于生成交给 Claude Code / OpenAI Codex 的执行 prompt。

## 1. 不要重复的内容

生成 prompt 时，不要重复以下固定规则正文：

```text
1. 不要重复 CLAUDE.md 中的固定编码流程。
2. 不要重复 ai_shared/rules/reporting.md 中的最终反馈格式。
3. 不要重复 ai_shared/rules/coding.md / testing.md / validation-routing.md 的完整规则。
4. 不要重复 skill 全文。
5. 不要写 report 模板。
```

生成 prompt 只需要写清楚本轮任务目标、事实基线、必须读取的上下文、允许/禁止修改范围、三个 subagent 的 handoff 内容、验收标准和报告目标。

## 2. 生成 prompt 前必须知道的 agent

仓库已固定使用三段式 agent 流程：

```text
@agent-code-implementer -> @agent-test-validator -> @agent-project-steward -> 主会话收口
```

三个 agent 的职责如下：

```text
code-implementer：
- 编码、必要中文注释、Google-style docstring、相关测试修改。
- 必须使用 changed-files-gate 和 code-quality-gate。
- 必要时使用 project-tree-read。
- 不负责长期文档归档。

test-validator：
- 独立验证真实工作区变更。
- 必须使用 changed-files-gate 和 code-quality-gate。
- 负责 py_compile / ruff / mypy / pytest 等验证和失败分类。
- 不修改源码、测试或文档。

project-steward：
- 根据已验证证据更新 report、project_tree、ADR、需求跟踪表和规则。
- 必须使用 changed-files-gate。
- 按需使用 project-tree-update、requirement-trace、adr-upsert、report-archive、rule-update。
- 不修改源码和测试，除非本轮 prompt 明确授权。
```

## 3. 可用 skills

生成 prompt 时，可以在 handoff 的 `skills to use` 中引用以下 skill：

```text
changed-files-gate
code-quality-gate
project-tree-read
project-tree-update
project-tree-reset
requirement-trace
adr-upsert
report-archive
rule-update
heavy-regression
commit-message
feedback-archive
```

不要在 prompt 中复制 skill 细则，只写需要使用哪些 skill。

## 4. 可用 memory / 文档入口

生成 prompt 时，按任务需要选择，不要默认全读：

```text
ai_shared/memory/project_tree.md
ai_shared/memory/Whale_REQ_Ingest.md
ai_shared/memory/Whale_REQ_*.md
ai_shared/memory/Whale项目说明.md 或其他文件名含“项目说明”的文件
ai_shared/adr/ADR索引.md
ai_shared/reports/<上一轮报告>.md
```

注意：

```text
1. project_tree 只用于定位，不替代源码读取。
2. 需求、ADR、报告只在本轮需要时列入 required files。
3. 真实事实必须以当前源码、测试、配置、schema 为准。
```

## 5. Prompt 输出格式

下面是网页版 LLM 应输出给 coding agent 的 prompt 格式。

---

# 第{ROUND_NO}轮_共{TOTAL_ROUNDS}轮：{TASK_TITLE}

## 0. 本轮唯一目标

```text
{ONE_SENTENCE_GOAL}
```

## 1. 当前事实基线

```text
1. {BASELINE_1}
2. {BASELINE_2}
3. {BASELINE_3}
```

## 2. 必读上下文

只读取以下文件；不要默认读取全部 docs / ADR / reports / project_tree。

```text
CLAUDE.md
ai_shared/rules/routing.md
{REQUIRED_CONTEXT_1}
{REQUIRED_CONTEXT_2}
{REQUIRED_CONTEXT_3}
```

说明：

```text
1. 如果使用 project_tree，只能用于导航。
2. 定位后必须二次读取真实源码、测试、配置、schema。
3. 如果文件不存在，必须先说明，不得凭记忆补。
```

## 3. 允许修改

```text
{ALLOWED_PATH_1}
{ALLOWED_PATH_2}
{ALLOWED_PATH_3}
```

## 4. 禁止修改

```text
{FORBIDDEN_PATH_1}
{FORBIDDEN_PATH_2}
{FORBIDDEN_PATH_3}
```

## 5. @agent-code-implementer handoff

```text
Agent handoff:
- task:
  - {IMPLEMENT_TASK}
- allowed paths:
  - {ALLOWED_PATH_1}
  - {ALLOWED_PATH_2}
- forbidden:
  - {FORBIDDEN_PATH_1}
  - {FORBIDDEN_PATH_2}
- required files:
  - ai_shared/rules/routing.md
  - {IMPLEMENT_REQUIRED_FILE_1}
  - {IMPLEMENT_REQUIRED_FILE_2}
- changed files:
  - 使用 changed-files-gate，编码前后各执行一次
- evidence available:
  - {IMPLEMENT_EVIDENCE_1}
- rules to read:
  - routing 指定的 coding / testing / validation / quality / docstring 规则
- skills to use:
  - changed-files-gate
  - code-quality-gate
  - project-tree-read if needed
- commands to run:
  - {IMPLEMENT_COMMAND_1}
- expected output:
  - Agent result
```

## 6. @agent-test-validator handoff

```text
Agent handoff:
- task:
  - 独立验证 code-implementer 的真实变更
- allowed paths:
  - read-only
- forbidden:
  - 不得修改源码、测试、文档
- required files:
  - ai_shared/rules/testing.md
  - ai_shared/rules/validation-routing.md
  - ai_shared/rules/quality-gate.md
  - ai_shared/rules/python-docstring-cn.md
  - {VALIDATE_REQUIRED_FILE_1}
- changed files:
  - 使用 changed-files-gate 获取真实变更文件
- evidence available:
  - code-implementer Agent result
- rules to read:
  - testing
  - validation-routing
  - quality-gate
  - python-docstring-cn
- skills to use:
  - changed-files-gate
  - code-quality-gate
- commands to run:
  - {TEST_COMMAND_1}
  - {TEST_COMMAND_2}
  - {TEST_COMMAND_3}
- expected output:
  - Agent result
```

## 7. @agent-project-steward handoff

```text
Agent handoff:
- task:
  - 根据已验证结果更新文档、目录树、ADR、需求跟踪和报告
- allowed paths:
  - ai_shared/
  - {DOC_ALLOWED_PATH_1}
- forbidden:
  - src/
  - tests/
  - tools/
  - 除非本 handoff 明确授权，不得改源码和测试
- required files:
  - ai_shared/rules/documentation.md
  - ai_shared/rules/reporting.md
  - ai_shared/memory/project_tree.md
  - {DOC_REQUIRED_FILE_1}
- changed files:
  - 使用 changed-files-gate 获取真实变更文件
- evidence available:
  - code-implementer Agent result
  - test-validator Agent result
- rules to read:
  - documentation
  - reporting
- skills to use:
  - changed-files-gate
  - project-tree-update
  - requirement-trace if needed
  - adr-upsert if needed
  - report-archive
  - rule-update if needed
- commands to run:
  - {DOC_COMMAND_1}
- report target:
  - ai_shared/reports/{REPORT_FILE_NAME}.md
- expected output:
  - Agent result
```

## 8. 验收标准

```text
1. 本轮引入 failed = 0，或明确环境 pending。
2. Python 改动已考虑 py_compile / ruff / mypy / pytest。
3. 行为变化有测试证据。
4. 新增、删除、移动、重命名、职责变化文件已触发 project-tree-update 判断。
5. 需求状态没有高估。
6. 报告和最终反馈能追溯到 Agent result。
```
