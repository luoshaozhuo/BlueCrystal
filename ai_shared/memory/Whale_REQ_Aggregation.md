# Whale_REQ_Aggregation

## 一、文件定位

本文件描述 Whale aggregation 模块需求。aggregation 负责实时聚合、周期聚合和业务主题聚合。

本文件不描述 source 接入、raw 写入和基础清洗逻辑。

## 二、上承项目级需求

| 项目级需求 | 本模块承接方式 |
|---|---|
| P-FR-005 | 承接业务主题聚合和服务层数据构建 |
| P-DGR-001 | 承接口径、规则版本和可重算 |

## 三、功能需求

### AG-FR-001 实时聚合

- 类型：功能
- 优先级：高
- 需求描述：
  - aggregation 模块应支持基于 speed layer 或 serving cache 的实时聚合。
- 验收要点：
  - 支持窗口聚合。
  - 支持质量码和迟到数据策略。

### AG-FR-002 周期聚合

- 类型：功能
- 优先级：高
- 需求描述：
  - aggregation 模块应支持基于 standard layer 或 warehouse layer 的周期聚合。
- 验收要点：
  - 支持小时、日、月等周期。
  - 支持补跑和重算。

### AG-FR-003 业务主题聚合

- 类型：功能
- 优先级：高
- 需求描述：
  - aggregation 模块应支持面向风电、储能、并网点、设备健康、能量统计等业务主题的聚合。
- 验收要点：
  - 输出主题数据集。
  - 支持服务层读取。

## 四、非功能需求

### AG-NFR-001 一致性与可重算

- 类型：非功能
- 优先级：高
- 需求描述：
  - aggregation 模块应保证聚合口径、时间窗口、质量规则和版本可追踪。
- 验收要点：
  - 记录 aggregation_rule_version。
  - 支持历史重算。

## 五、架构约束

### AG-AR-001 聚合层职责边界

- 类型：架构约束
- 优先级：高
- 需求描述：
  - aggregation 不直接连接现场 source，不负责 raw 写入。
- 验收要点：
  - 输入来自 standard、warehouse、speed 或 serving 层。
  - 输出到 warehouse/mart/service。

## 六、测试与验收需求

### AG-TEST-001 聚合测试

- 类型：测试与验收
- 优先级：高
- 需求描述：
  - aggregation 模块必须具备实时聚合、周期聚合和业务聚合测试。
- 验收要点：
  - 覆盖窗口边界、迟到数据、质量码、补跑重算。
