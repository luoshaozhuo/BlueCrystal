# Whale_REQ_Processing

## 一、文件定位

本文件描述 Whale processing 模块需求。processing 负责从 raw layer 到 standard layer 的清洗、标准化、质量处理、时间对齐和回灌。

本文件不描述实时消费和聚合计算。

## 二、上承项目级需求

| 项目级需求 | 本模块承接方式 |
|---|---|
| P-FR-004 | 承接数据标准化和质量处理 |
| P-DGR-001 | 承接数据血缘、schema 版本和可追溯 |

## 三、功能需求

### PR-FR-001 raw -> standard 处理

- 类型：功能
- 优先级：高
- 需求描述：
  - processing 模块应从 raw layer 读取数据，完成清洗、标准化、时间对齐和质量处理，并写入 standard layer。
- 验收要点：
  - 支持批次输入。
  - 支持标准化输出。
  - 支持质量码处理。

### PR-FR-002 数据清洗与异常处理

- 类型：功能
- 优先级：高
- 需求描述：
  - processing 模块应处理缺失值、异常值、重复值、乱序数据和迟到数据。
- 验收要点：
  - 清洗规则可配置。
  - 处理结果可追溯。

### PR-FR-003 补采回灌与版本兼容

- 类型：功能
- 优先级：高
- 需求描述：
  - processing 模块应支持补采、回灌、历史重算和 schema version 兼容。
- 验收要点：
  - 支持回灌批次标识。
  - 支持版本兼容策略。

## 四、非功能需求

### PR-NFR-001 可复算与可追溯

- 类型：非功能
- 优先级：高
- 需求描述：
  - processing 模块应保证处理过程可复算、处理规则可版本化、处理结果可追溯。
- 验收要点：
  - 记录 rule_version、input_range、output_range、job_id。

## 五、架构约束

### PR-AR-001 处理层职责边界

- 类型：架构约束
- 优先级：高
- 需求描述：
  - processing 不直接连接现场 source，不负责实时消息消费和 serving cache 更新。
- 验收要点：
  - 输入来自 raw layer 或 batch layer。
  - 输出到 standard layer。

## 六、测试与验收需求

### PR-TEST-001 处理规则测试

- 类型：测试与验收
- 优先级：高
- 需求描述：
  - processing 模块必须具备清洗、标准化、质量处理、回灌和 schema 兼容测试。
- 验收要点：
  - 覆盖正常数据、异常数据、缺失数据、乱序数据、重复数据。
