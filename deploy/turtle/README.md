# Turtle 治理基础能力部署

Turtle 提供跨 Whale 模块的全局治理、安全、合规、审计和策略基础能力。

## 子包说明

- auth: 认证授权（identity、principal、access policy）
- security: 安全基础（密钥引用、凭证引用、TLS 配置）
- compliance: 合规基础（审计事件、数据分类、保留策略）
- audit: 审计治理
- policy: 策略治理
- governance: 治理框架
- risk: 风险评估
- deployment_policy: 部署策略
- change_control: 变更控制
- ports: 端口定义
- adapters: 适配器实现
- api: API 端点
- runtime: 运行时配置
- sdk: 客户端 SDK

## 部署方式

Turtle 当前以 Python 包形式嵌入各 Whale 模块部署。未来可独立部署为治理服务。
